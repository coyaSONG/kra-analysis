Maintain this ExecPlan under .agent/PLANS.md in the isolated research

## Purpose / Big Picture

The October runners bind the original 50 races and cannot run a later
card. A released new card can now be witnessed as a whole, but a witness
only proves the existence of inputs. Connect that proof to a separately
approved, once-only execution and prebound prediction publication for
the two unchanged models. No dates or review identities are registered
by implementing this path.

## Surprises & Discoveries

The October series identifiers are built into the original evaluator
and the model is separate from its forward series. Its numerical loader
can be reused without editing those series. The previously prepared
November material is past its original cutoff; its intact files cannot
authorize a new execution.

## Decision Log

Use an owner-authored merged protocol to designate a different reviewer.
That reviewer's separate merged approval must bind the exact protocol.
Both documents must be verified in their original GitHub merge trees
and be committed on main at execution. A real open owner-side prediction
PR has to be named in advance. The input witness, protocol, independent
approval and prediction use distinct PRs. Merely generating a local
protocol is not authority. The required code release checks remain the
normal repository process and may not be bypassed.

Use the original result-policy identifier, M0/API27 model and fit receipt
hashes, two distinct complete slots per race, and the same source
projection for both models. Reserve all original dates in the common
Git directory before consuming the first attempt. Leave failures in
that reservation; never substitute another roster or prediction after
the original cutoff. No production fit, network data acquisition, or
automatic promotion is included.

## Outcomes & Retrospective

The end-to-end synthetic run retained two dates, all four physical
venues, 14 races, 140 declarations and five source-shaped mock pages.
The GitHub authority simulation read only five responses at execution
and two at prediction witness. It rejected wrong review authors, late
merge, wrong bytes, changed runtime, overlapping scopes and retries.
The checked exact private packet contained one slot for each model
per original race, with a common input digest. Injecting a nonfinite
score affected only the corresponding slot.

In a separate local readback the unchanged frozen model loaders were
used with those same fictional features; an independent arithmetic
implementation reproduced all 28 selections. No fitting, real data
requests, outcome lookups, or authorized live predictions occurred.
The 597-test suite passed in 50.14 seconds; Ruff lint and formatting
and the October commitment byte hashes passed. Reusing the original
versioned result policy to score this new output remains a separate
post-race step. No actual future study or model execution is approved.

attempt directory and survives an interruption at directory creation.

future study cannot replace its
calendar dates. Keep unknown publication evidence separate from late
evidence. Do not retry requests automatically.
